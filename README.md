## Zasady publikowania kolejnych raportów HTML

1. **Każdy nowy raport otrzymuje własną, czytelną nazwę pliku HTML**, złożoną z krótkich słów opisujących temat, np. `analiza-rynku-ai-2026.html`. Nazwy stosują małe litery, cyfry i myślniki (kebab-case). Nie publikujemy kolejnych raportów pod nazwą `index.html`.
2. **Każda publikacja lub istotna aktualizacja raportu wymaga aktualizacji `README.md`**. Dodaj lub zmodyfikuj wpis w tabeli: data publikacji, tytuł, krótki opis i publiczny link.
3. Nowe raporty umieszczamy w tabeli **od najnowszych**. Gdy aktualizowany jest istniejący materiał, aktualizujemy jego dotychczasowy wpis zamiast tworzyć duplikat.
4. Publiczny adres raportu ma format `https://sebastiandabkowski.github.io/seba-info/<nazwa-pliku>.html`.
5. `index.html` pozostaje punktem wejścia do serwisu. Nowe raporty zapisujemy pod osobnymi nazwami, nie nadpisując przypadkowo strony głównej.
6. Przed publikacją w publicznym repozytorium sprawdzamy, czy raport nie zawiera poufnych danych, danych osobowych ani informacji objętych NDA.

### Dla asystenta publikującego przez GitHub

Przy każdej prośbie o dodanie strony HTML do repozytorium `SebastianDabkowski/seba-info`: sprawdź istniejące pliki, nadaj nazwę opisową, dodaj lub zaktualizuj HTML, uaktualnij `README.md` oraz zwróć link do opublikowanej strony. Nigdy nie zakładaj, że wystarczy samo zapisanie pliku HTML.

> Historycznie pierwszy raport jest także dostępny pod adresem strony głównej (`index.html`). Jego nazwany plik to `finance-performance-cockpit.html`.
